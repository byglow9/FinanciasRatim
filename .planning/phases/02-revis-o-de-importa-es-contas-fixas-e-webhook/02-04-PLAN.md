- Regras: `updatedAt` é `bankUpdatedAt` se existir (fonte `bank`), senão `lastSyncAt` (fonte `sync`), senão nulo (fonte `none`). `ageHours` é a diferença em horas (não arredondada). `stale` é verdadeiro se `ageHours > staleHours`, e também verdadeiro quando não há data alguma (não dá para garantir frescor). `consent`: `none` se `consentExpiresAt` é nulo; `expired` se `consentExpiresAt <= now`; `expiring` se `daysToExpire <= expiringDays`; senão `ok`; `daysToExpire` é `Math.ceil` dos dias restantes, 0 quando vencido, nulo quando `none`. `needsReconnect` é verdadeiro se `consent === 'expired'` ou `status` é `LOGIN_ERROR`, `WAITING_USER_INPUT` ou `WAITING_USER_ACTION`. `level`: `error` se `needsReconnect`; senão `warn` se `stale`, `consent === 'expiring'`, `status === 'OUTDATED'` ou `executionStatus === 'PARTIAL_SUCCESS'`; senão `ok`. Status desconhecido nunca lança erro.
- Textos (pt-BR): "Atualizado há 3 horas" (`formatDistanceStrict(updatedAt, now, { locale: ptBR, addSuffix: true })` precedido de "Atualizado"); sem data: "Sem registro de atualização"; fonte `sync`: "Última importação do app há X"; consentimento vencido: "Consentimento vencido"; perto de vencer: "Consentimento vence em N dias"; precisa reconectar sem consentimento vencido: "Precisa reconectar"; desatualizado: "Dados do banco desatualizados"; evidência do webhook (só se `lastWebhookAt` existe): "Último aviso do banco: há X".
