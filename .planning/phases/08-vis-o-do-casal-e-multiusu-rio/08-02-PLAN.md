## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cliente para Firestore | o cliente escolhe o id do documento ao criar; só as regras garantem que o id é do próprio grupo |
| grupo A para grupo B | documentos compartilham as mesmas coleções; o isolamento é por ownerId e, agora, por id com prefixo |
